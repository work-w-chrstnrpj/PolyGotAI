## Destinations and identity

Personal bookmarks accept absolute HTTPS URLs with a syntactically public DNS hostname. Reject embedded username/password, non-443 ports, invalid/control/backslash forms, IP/numeric hosts, single-label/local/reserved host suffixes and explicit credential query fields (token/access_token/api_key/apikey/password/auth/authorization/signature). Validation does not resolve DNS, certify safety, authenticate an external publisher or validate a redirect chain. A named public host can be unavailable or resolve differently later. External navigation belongs to the system/browser after explicit confirmation; it can apply the destination's own redirects, tracking, cookies, sign-in and terms.

Canonicalization lowercases scheme/host, removes an explicit default 443 port, supplies an empty root path and drops utm_*, fbclid and gclid fields. Other general-site query parameters and fragments retain their meaning/order. Tracking removal operates on the original percent-encoded query fields, preserving escaped plus signs, nested destinations, flags, repeated fields and explicit empty queries; it does not decode and rebuild retained values. Equivalent arbitrary website URLs are not claimed to be universally detectable. Exact canonical duplicates are refused rather than silently overwriting notes.

Recognized YouTube hosts are youtube.com/www/m/music and youtu.be/www. Video watch/shorts/live/embed/short-link forms with one valid eleven-character video ID become `https://www.youtube.com/watch?v=ID`, without tracking, time or playlist context. Channel-ID and ASCII handle links become canonical www.youtube.com channel/handle destinations. Unsupported forms, ambiguous repeated video IDs, playlists and redirects are refused with an editing message. A YouTube-looking subdomain of another site remains that other site's host. The confirmation displays the actual canonical destination.

## Privacy, persistence and deletion

Only explicit Save stores a bookmark's title, canonical destination, topic and notes locally in the protected, backup-excluded existing learner document. No provider request, external note submission or separate database. Stored optional Codable `learningResources` preserves old schema-v1 documents without a SwiftData migration. Each record has UUID, revision, optional curated ID/version and update date. Saved notes remain until explicit removal or Delete all learning data. Bookmark removal explicitly confirms permanent removal of that bookmark and notes; it does not delete an external account/site. Existing recorded-attempt Recently Deleted behavior is unchanged.

Unsaved edits are in memory across view/sidebar changes only, with explicit discard confirmation and no process-restart recovery promise. Failed saves preserve drafts and the previous durable value for retry. Settings writes retain resources. Writes/removals require the current learner epoch; edits/removals also require the exact original record. Delete-all makes stale drafts/operations invalid, and a later save/open cannot restore that content. Read failures do not replace saved data with an empty write.

No export/restore feature is introduced. Resource notes are not uploaded, logged, included in provider context or automatically exported. Any later selected export must explicitly include this scope under SC-D020; this does not waive that group's original export/restore requirements.

## Availability and native UI

Learn opens the library without leaving or completing a lesson. Titles/notes, editing and saving work offline. Network path observation sends no request to the site; an unavailable path disables external opening and explains why. A satisfied path is not a site-availability check. Each deliberate Open website creates an intent bound to current epoch and displayed bookmark revision; confirmation revalidates before invoking SwiftUI OpenURLAction. Cancel sends nothing. System refusal displays a recoverable error and preserves the bookmark. System acceptance means URL handoff only, not successful loading or content verification. Returning/foregrounding refreshes storage and connectivity; stale callbacks are ignored after reset.

Native fields have persistent labels, URL keyboard and Dynamic Type; editor uses explicit Save/Cancel and protects dirty sheet dismissal. Library uses existing Kit cards, Content row and Status with adaptive controls, scrollable long content and native navigation.
