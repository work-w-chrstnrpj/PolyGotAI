# Getting started

1. Read [AGENTS.md](../AGENTS.md), then [history-version.md](history-version.md) to see why the project looks the way it does.
2. Read the [development plan](development-plan/development-plan.md) and the current phase folder in `development-plan/phases/`.
3. For the feature you're touching, read the matching spec: [product](product-specification/product-specification.md), [coach tracks](product-specification/coach-tracks.md), [Speech Lab](product-specification/speech-lab.md), [technical design](tdd/tdd.md).
4. For UI work, follow the [UI reference guide](product-specification/ui-reference-guide.md) and reuse the components in `Features/Shared/DesignSystem.swift`.
5. Open `application/SpeechCoachAI.xcodeproj` (scheme `SpeechCoachAI`) and run on a simulator, or run the [main check](commands/commands.md).
