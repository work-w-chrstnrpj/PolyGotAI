# Issue Tracker

**Tracker:** github

<!-- Written by the installer. Values: local | github | other. Skills read this file to know where tickets live. -->

## local

- Tickets: `tickets/<feature>/NN-<slug>.md`, one file per ticket, spec in `tickets/<feature>/spec.md`.
- Ticket ID: `<feature>/NN`.
- Status: the `**Status:**` line. Blockers: the `**Blocked by:**` line. History: `## Progress log`.
- Board: `tickets/BOARD.md`, regenerated by `node .ai/cli/bin/cli.mjs status --write`.

## github

- Tickets: GitHub Issues via `gh`. Ticket ID: `#<number>`.
- Status: one state label from `triage-labels.md`. Type: a `type:<name>` label.
- Blockers: native blocking links, or a `## Blocked by` section listing `#numbers`.
- Progress log and evidence: issue comments; the final evidence comment starts with `## Evidence`.
- Specs: an issue labelled `spec`; tickets are its sub-issues.
