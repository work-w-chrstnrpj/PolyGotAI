## Clarified context boundary

The trainer-specific learning checks apply to optional specialist packs, not different versions of the required CEFR course. Use [CP-QA01–03/08](course-practice-and-rewards-acceptance.md) to verify identical CEFR training across all seven presenting coaches and explicit specialty detours with saved return context. A presentation-only change is not a pedagogical method change.
