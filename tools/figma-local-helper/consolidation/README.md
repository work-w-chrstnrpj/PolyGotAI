## Build and use

```sh
node tools/figma-local-helper/consolidation/build.mjs
node --check tools/figma-local-helper/consolidation/code.js
```

The imported plugin is **SpeechCoach Page 1 Kit**, under Figma Desktop → Plugins → Development. Close any running instance and reopen it after rebuilding. If import is needed, select this folder's `manifest.json`.

1. Launching now runs the fixed build/verification operation automatically, to avoid unreliable iframe-button automation. It builds only if no named kit exists; otherwise it audits the existing kit without rebuilding or changing it. It never removes Page 2 on launch. A long-lived notification and a `SPEECHCOACH_KIT_REPORT` console message provide structural results; connection errors use `SPEECHCOACH_KIT_ERROR`.
2. Construction ran successfully; a future failed operation may leave partial work. Use normal Figma Undo and inspect before retrying. Do not rerun blindly if construction stopped after starting.
3. Use Export review and inspect every section for clipping, contrast, reflow and preserved artwork. The export packages PNGs and its audit report into one ZIP through the normal plugin download UI, retaining the blob URL for the lifetime of the plugin. Resolve defects before removal.
4. Remove Page 2 only after the retained kit passes review. The operation checks retained original IDs, horizontal bounds and component dependencies, removes links to the deleted page, and uses normal recoverable Figma deletion/Undo. It does not purge file history.
5. Save report and verify only Page 1 remains, then confirm Figma cloud sync.

`plugin.js` contains the fixed operation dispatcher and inspection. `kit.js` contains construction/audit/removal. `startup.js` contains the fixed launch operation. `code.js` is generated by `build.mjs`. No application test/build claims follow from a JavaScript syntax check.
